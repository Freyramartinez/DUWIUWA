## Descripción

**WOMEN SAFETY** es una plataforma web orientada a la presentación y gestión de servicios. El proyecto se encuentra actualmente en desarrollo y sus funcionalidades serán incorporadas progresivamente conforme avance cada sprint.

---

# Funcionalidades

| Funcionalidad             | Descripción                                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Menú de navegación**    | Permite al usuario desplazarse entre las diferentes secciones disponibles dentro de la plataforma.    |
| **Slider**                | Componente encargado de presentar información destacada de manera dinámica.                           |
| **Catálogo de servicios** | Permite visualizar y consultar los servicios disponibles dentro de la plataforma.                     |
| **¿Quiénes somos?**       | Sección destinada a presentar información sobre la organización y el equipo responsable del proyecto. |
| **Ubicación**             | Permite consultar la ubicación mediante la integración de un mapa.                                    |
| **Base de datos**         | La información dinámica del sistema será almacenada utilizando **MongoDB Atlas**.                     |
